# Streetwise Connection — Service Catalogue v1

## CONNECT

### Wi-Fi Setup
Configure and optimise a home or small-business Wi-Fi network.

### Router Configuration
Configure supported routers, security settings, network names, passwords, and basic network options.

### Mesh Wi-Fi Setup
Install and configure supported mesh systems and optimise placement/settings.

### Network Troubleshooting
Diagnose common connectivity, configuration, performance, and device-connection problems.

### Network Setup
Design and configure a practical home or small-business network.

### Network Documentation
Create a simple record of network equipment, configuration, and connection information.

## SUPPORT

### Computer Setup
Set up supported Windows PCs or Macs, updates, accounts, applications, peripherals, and basic backups.

### Device Setup
Set up supported phones, tablets, printers, accessories, and other common consumer technology.

### Technical Troubleshooting
Diagnose software, configuration, connectivity, and common device problems.

### Data Migration
Assist with moving customer data between supported devices and systems.

### Backup Setup
Configure practical local or cloud backup solutions supported by the customer's equipment.

### Remote Technical Support
Provide remote assistance for problems that can be safely resolved without physical access.

### Technology Guidance
Explain technology clearly and help customers make practical configuration decisions.

## SECURE

### Account Security Review
Review common account-security settings and identify practical improvements.

### MFA Setup
Configure multi-factor authentication on supported accounts.

### Password Manager Setup
Help customers configure and use a reputable password manager.

### Device Hardening
Apply practical security settings, updates, access controls, and safer defaults.

### Router Security
Review and configure supported router security settings.

### Privacy & Security Configuration
Help configure privacy, permissions, browser, device, and account security settings.

### Security Awareness
Provide practical guidance on phishing, scams, suspicious links, account recovery, and safer technology use.

### Basic Security Assessment
Review a customer's authorised environment for common defensive weaknesses. No unauthorised testing.

## BUSINESS

### Business IT Setup
Set up computers, user accounts, peripherals, networking, and core technology for a small business.

### Microsoft 365 Setup
Configure supported Microsoft 365 accounts, users, email, and collaboration services.

### Google Workspace Setup
Configure supported Google Workspace accounts, users, email, and collaboration services.

### Business Network Setup
Configure a practical small-business network, Wi-Fi, routers, and access points.

### Device Deployment
Prepare and configure multiple employee devices.

### Backup & Recovery Planning
Design practical backup procedures for small-business systems.

### IT Documentation
Document devices, accounts, networks, services, and basic operational procedures.

### Ongoing Business IT Support
Provide recurring technical assistance, maintenance, and technology guidance.

## Delivery

Services may be delivered:

- On-site where physical access is required.
- Remotely where the task can be performed safely and effectively.

## Customer safety

Customers should retain control of passwords, authentication codes, recovery codes, payment information, and identity documents. Streetwise should request the minimum information necessary to perform a service.

## Service-status language

A service must be marked **Available**, **Coming Soon**, or **Not Offered** before publication. Do not advertise capabilities that have not been validated.
