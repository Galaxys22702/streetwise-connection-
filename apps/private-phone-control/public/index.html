Do not change

  • Never deploy, merge, modify Railway/Cloudflare/DNS, touch production data or open network ports.
  • Never paste keys, full phone numbers or message bodies into this site or repo.

Platform integration contract

Once you have an authorized Android, iOS-supported provider, VoIP or desktop bridge, it sends only kind, a non-sensitive reference, and optionally the last four digits to the local controller using the scoped key for that device. Inbound acceptance updates the screen but does not verify a real telecommunications event by itself. Device connector authentication, encrypted remote transport, quotas, and provider receipts must all be completed before real remote use.

Localhost onlyDo not forward port 8789 to the Internet or change 127.0.0.1 to 0.0.0.0. A private, authenticated HTTPS relay is separate work.

Local privacy control

Erase all locally stored devices, redacted events, verification records and audit entries. This is irreversible unless you made a separate private backup. It never deletes carrier messages or external service records.
